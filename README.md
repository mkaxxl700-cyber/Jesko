# JESKO TAXI

**JESKO TAXI** is a long-term mobility project based in Dushanbe, Tajikistan. Its phased implementation is planned over the coming years.

This repository contains the project's multilingual presentation website and frontend source.

## Project status

The project is in its foundation and development stage. The brand direction, visual identity, website and concept for the future service are being developed. The roadmap describes intended stages, not completed operations. No ride service is currently available and no launch date has been announced.

## Website

- Russian, Tajik and English language versions
- Responsive layout for desktop, tablet and mobile
- Mobile navigation menu
- Language preference saved in the browser when storage is available
- Project status and phased development roadmap
- Accessible skip navigation and reduced-motion support
- No build tools or package installation required

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

Open `index.html` in a modern browser. The site does not require a build step or local server for a basic preview.

## Publishing

This repository is intentionally **private**. GitHub Pages on GitHub Free for personal accounts requires a public repository. Do not make this repository public just to publish the website. Hosting can be configured later on an appropriate plan or through a separate public deployment repository, without exposing private project files.

## Before an operational launch

- Confirm the legal and business structure of the service.
- Finalize service areas, operating model and customer support channels.
- Replace external stock photography with approved brand assets.
- Publish real contact details only after official channels are established.
- Add booking, dispatch and payment integrations only after service infrastructure is ready.
